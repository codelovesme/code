A programming language built on constraints, not assignment.

Variables narrow a domain of possible values instead of being set imperatively. There are no user-defined functions — reusable logic is handler dispatch. No install needed to try it.

∈ Constraint variables

A variable holds a domain, not a single value — a > 5, a < 10, a ∈ Z all narrow it. Assignment is a special case: a domain of exactly one value.

⇒ Handlers, not functions

There's no name(args) call syntax anywhere in the grammar. emit X to target get result is the only reusable-logic primitive — and it composes across modules.

= Single assignment

A name is bound once. Combined with no recursion and bounded loop … over iteration, a program's total work is always statically bounded.

∅ No core I/O

The interpreter never writes to stdout. A program's visible result is its final top-level bindings — which is exactly what the playground shows you.
