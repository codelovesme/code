code

An early, from-scratch language. Right now: name = expr bindings that are untyped and always reassignable, over a value model that is exactly JSON's six kinds — number, string, boolean, null, array, object — with no type keywords anywhere. This page runs the actual interpreter, compiled to WebAssembly, in your browser.
