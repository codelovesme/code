01 Values

Seven kinds of value: Number, String (with $name interpolation), Boolean, Null, Object ({ field = expr, ... }), Array ([ ... ], ordered, allows duplicates), and Set ({ ... } with bare elements, unordered, deduplicated — an empty {} is always an empty Object, there's no empty-set literal).

A comparison against an unresolved variable is decided directly from its domain whenever the domain settles it either way — assert b > 5 holds if every value b could still be satisfies it, no resolution required.

04 Set operators

∪ (union) and ∩ (intersection) work on Set values, Schema values (merging field constraints — this is how particle types compose, see below), and Union values. An unresolved-but-finite scalar domain is materialized into a Set automatically, so it works on those too without pinning first.

05 Particle types

A particle type is a schema built from the predefined Particle base (_class ∈ String, _created ∈ Number) merged with field constraints via ∩, with _class pinned to the type's own name explicitly. There's no separate keyword — Log = Particle ∩ { _class ∈ "Log", ... } is an ordinary variable binding. Constructing Log { ... } validates against it: every non-optional field must be present, every field's value must satisfy its declared domain, and no unknown fields are allowed.

__EXAMPLE__reference_particles__
Optional fields. A field typed ∪ Null may be omitted — it defaults to Null rather than erroring as missing.

06 Handlers & dispatch

Code has no user-defined functions — reusable logic is a handler: ClassName => { body }, invoked with emit <particle> to <target> get <result>. A particle's fields are bound into the handler body's scope by name — no parameter list.

TargetDispatches to
thisA handler defined in the current file.
baseThe module that linked this one.
coreA built-in handler — see Core handlers.
aliasA handler in a module linked as alias.

07 Loops

FormBound
loop v over arr get r { }The array's length.
loop v get r { }The size of v's own finite domain.
loop get r { }None — runs until an explicit break.
__EXAMPLE__reference_loops__
There's no while and no C-style counter. yield <expr> inside any of the three forms appends to the named result.

08 Modules

A module is just another .code file. link <path> [as <alias>] brings its public top-level bindings and handlers into scope — aliased, they're reached as alias.name / emit ... to alias; unaliased, they're flattened directly into the current scope.

10 CLI

Four commands. code test always scans tests/ relative to the current directory — run it from the repository root.

code run <file.code>

Interpret and execute a file directly.

code build <file.code> [--target exe|ir|shared|static|wasm] [--release]

Compile natively via LLVM. Default target is a native executable; --release optimizes.

code fmt <path> [--check]

Format a file or every .code file under a directory, in place. --check reports whether anything would change without writing.

code test

Run every .code fixture in tests/ and report pass/fail counts.
