Build once. Reuse a valid build.

The run cache keeps your program’s native executable. Each run checks whether the inputs still match.

  1. First run→Build and cache→Run
  2. Unchanged inputs→Validate and reuse→Run
  3. Changed inputs→Rebuild as needed→Run updated program

Source files, linked modules, lockfiles, the compiler, target and optimization tier affect validity. A missing or invalid cache takes the build path again. "$code_cli" cache shows where the cache lives.

Launcher, optimization and interpreter fallback

The Linux release contains code, a lightweight launcher, and code-driver, the compiler/full CLI. Keep them together. A valid ordinary warm run starts the executable through the launcher; other commands and cache misses reach the driver.

Small programs get an optimized build before the first run. Larger programs can start on a quick build while an optimized build is prepared in the background for later runs. Your program still runs once per invocation.

When a native build is unavailable, such as without the required compiler/linker, code run can use the interpreter. --interpret selects it explicitly; code build requests a compiled artifact. Versioned execution reference ↗

Two ways to use WebAssembly.

Compile your application, or embed the language interpreter. Each path has its own host and module requirements.

Compile your program

  1. Your Code source
  2. code build --target wasm
  3. Application .wasm + generated host.mjs
  4. Browser runs the compiled program

The compiled application carries its program logic. Supply the matching browser modules and serve the generated host beside it.

Build and serve this greeting

The browser build needs the WebAssembly linker (wasm-ld). From a separate working directory, create a browser project and save the same main.code above:

"$code_cli" init browser-hello
cd browser-hello
"$code_cli" install console --platform wasm32
"$code_cli" build main.code --target wasm -o web/hello.wasm

Download the example host page ↓ into web/index.html, beside the generated hello.wasm and host.mjs.

python3 -m http.server 8000 --directory web

Open http://localhost:8000/. The page’s output is hello, world. Keep native and browser projects separate here: their module installs select different target assets.
