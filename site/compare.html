What the snapshot comparison includes

Each program initializes 128 × 4096 float64 cells, retains 64 pre-update versions plus the final matrix, and validates every full checksum. Initialization, scanning and cleanup are included.

C/Rust use dense 8-byte cells; Code uses generic containers. Rust’s shared version uses Rc::make_mut; C’s shared version uses explicit reference counts. This is a full-program comparison, not an isolated copy-on-write operation.

Sharing-study method and evidence

300 samples, none dropped. Each native program builds its input, retains 65 versions, verifies all values and releases them. Startup, construction, edits, validation and cleanup are timed; compilation is excluded. Configuration payloads stay unchanged while flags change. Text revisions replace one character per version.

C/Rust full-copy versions duplicate the payloads; shared versions explicitly manage references (C) or use Rc (Rust). Code uses generic values and automatic sharing. Document editing and validation use slices and concatenation in Code, private mutable buffers in C/Rust. Representations and validation costs differ: this measures complete programs, not an isolated sharing operation or a language-wide ranking.
