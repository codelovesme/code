5. Memory when keeping copies.

Keep 65 versions of a matrix while changing one cell per version. Compare automatic sharing with full copies and explicitly shared C/Rust representations.

__PERF_SNAPSHOTS__

Code uses 94.7% less peak RSS than Rust Vec clones on this program, but takes 1.81× the time. Explicit C/Rust copy-on-write is faster and leaner here. Complete-program times are in All results.

What the snapshot comparison includes

Each program initializes 128 × 4096 float64 cells, retains 64 pre-update versions plus the final matrix, and validates every full checksum. Initialization, scanning and cleanup are included.

C/Rust use dense 8-byte cells; Code uses generic containers. Rust’s shared version uses Rc::make_mut; C’s shared version uses explicit reference counts. This is a full-program comparison, not an isolated copy-on-write operation.

How these comparisons were measured.

485 retained samples on one fresh Linux VM. No samples dropped. Medians, exact ranges and the complete results stay on this page; raw evidence is available too.

Machine, versions and timing boundaries

Measured 4 November 2026, 22:23:35–22:24:24 UTC. Ubuntu 24.04.5, AMD EPYC 7763 model, four virtual CPUs, pinned to CPU 0. A hosted VM does not guarantee dedicated hardware or fixed frequency.

Public Code v2.23.0 (release source e7436b70ba33), GCC 13.3.0 at O2/O3, Rust 1.99.1 at O3, Python 3.12.3 and Node 22.23.4 / V8 12.4.254.21-node.57. C/Rust target the host CPU; Code uses its public release build pipeline.

Runtime groups have 15 launches; build groups have five. Groups run serially in seeded shuffled order. Prebuilt launches exclude compilation; source launches include preparation where required. Warm Code preserves its cached native artifact. RSS is the largest resident peak, not summed process-tree memory.

All targets validate their results. Representations differ, so this is a measured workload comparison rather than a language-wide ranking. Allocation counts and pause distributions were not measured.

Raw evidence and earlier measurements

All graphs use the same November public-release dataset. Older Java/Go measurements came from different hosts and development revisions; mixing them into these rankings would give a misleading comparison. They remain in the historical audit.
