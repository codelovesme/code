Send the item as a field in a LineTotal request. The handler multiplies count by price and returns a Line result.

__STEP_LINE__

2. Apply it to the cart.

Start total at zero. The loop calls the same handler for each item, adds the returned value and prints a readable line.

Add a check for negative counts and prices. The caller prints a message for an Exception; it adds only successful Line results to the total.
