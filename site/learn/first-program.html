The file is the same greeting you ran in the browser. This tutorial pins the console module to the same v2.24.1 release.

Check, run and build

check returns a JSON report with "diagnostics": [] when it finds no diagnostics. Each run prints hello, world. run --interpret uses the interpreter; run can reuse a cached native build. build --release creates build/hello, which you run on the final line.

Other platforms and building from source

The published native bundle used here is Linux x86_64. This release does not provide native CLI bundles for macOS, Windows or ARM. The browser playground remains an available starting point.

Building the language from source requires Rust, LLVM 17 and a system C compiler. Follow the versioned source-build instructions. Native platform support and module availability need checking for your target.
