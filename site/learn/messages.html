2. Inspect the result.

A handler can return an Exception particle when it cannot fulfill a request. The caller checks that returned value and decides what to do with it.

__STEP_FAILURE__

reply ∈ Exception checks the particle’s class. Here, an empty name returns a message to print. Change the request to name = "Ada" and the successful Greeting branch prints hello, Ada.

Returned failures, runtime failures and pre-run errors

Receiving an Exception does not automatically stop or propagate through the caller. Ignoring a returned failure lets the caller continue, so check results where they matter.

A runtime failure inside a handler ends that handler’s frame and returns an Exception. A failure at the top level, such as a failed assertion, stops the run. Errors found before execution, such as an undefined name or invalid syntax, refuse the program before it starts.
