# Code 2.24.1

This patch speeds up existing compiled programs that slice text and use string
length inside indexes. UTF-8 character positions, independent copied values,
clamping and error messages remain compatible; syntax, value layout and module
ABI 2 are unchanged.

Finite-bound text slices locate both character boundaries in one forward walk,
avoiding the previous full-input character count and repeated restarts. String
length counts continuation-byte bits in bounded eight-byte loads, with a scalar
tail. It keeps first-NUL behavior without new cache/header state, alignment
assumptions, ISA requirements or host imports.

Two separately controlled source studies retain every outcome:

- One-walk slicing: complete 1 MiB document histories took 273.388 → 147.846 ms
  (45.92% less elapsed time); peak RSS stayed 70.469 MiB.
  [Complete source study](https://github.com/codelovesme/code/blob/3f9f23c/benchmarks/document-slice/RESULTS.md).
- Character counting on top of that change: 257.369 → 185.443 ms on a different
  host (27.95% less elapsed time); peak RSS stayed 70.344 MiB.
  [Complete source study](https://github.com/codelovesme/code/blob/af3430d/benchmarks/character-count/RESULTS.md).

Each study retains 510 samples across 17 workloads, including small non-target
costs under its preregistered material-regression gate. These are paired source
measurements for complete programs, not language-wide speed claims, C/Rust
rankings or compounded cross-host gains. A later ASCII-specific experiment
regressed its large Unicode control and is **not included** in this release.

Rebuild compiled native/WebAssembly programs to receive these runtime changes.
The browser interpreter package shares the version; its Rust interpreter was
not the subject of these C-runtime optimizations. First-party modules, the
code-native crate, npm code-wasm, CLI bundle and VS Code extension all use
2.24.1. Keep the CLI launcher `code` and its adjacent `code-driver` together.
The released CLI is Linux x86_64; the VSIX includes Linux x86_64 and macOS arm64
language servers.

The retained implementation passed 343 workspace tests (seven ignored), Unicode,
bounds, alias and native/compiled-WASM checks, protected-page and sanitizer
probes, 178 browser-engine examples, and the frozen 102-application-fixture
regression corpus in both compiled modes. Current release validation and actual
package identities are recorded separately after publication.
