# Code 2.26.0

The `interpreter` module manages what it has loaded. Any program that links
it can check, replace, stop, start, inspect and unload its loaded programs
with particles alone — and expose that through its own endpoints, under its
own rights. Nothing in it belongs to one application.

```code
emit Check { source = rule, host = true } to plasmid get checked
| checked.ok, checked.modules, checked.offered, checked.missing — nothing ran

emit Replace { id = loaded.id, version = 1, source = better } to plasmid get replaced
emit Stop { id = loaded.id } to plasmid get stopped
emit Status { id = loaded.id } to plasmid get status
| status.version, status.hash, status.state, status.failures, status.errors
```

- **`Check`** examines source exactly as `Load` would — parse, undefined
  names, `link`, and with `host = true` which names the base offers — and
  runs none of it.
- **`Replace`** builds the new version whole (checked, bound, top level
  run) while the old one keeps answering; only then does it take its place,
  under the same `id`, as `version + 1`. Any refusal leaves the old version
  untouched. `version` refuses a replacer holding an old one (`stale`).
  The new top level has run by then: what it emitted is not undone.
- **`Stop` / `Start`** keep a program and its state while refusing its
  `Send`s; both are idempotent and say what it `was`.
- **`Status`** reports `version`, `hash` (`sha256:` of the running source),
  `state`, `busy`, `calls`, `failures` and the newest 16 failures — a
  `Send` that answered an `Exception`, a call to a base module that
  answered one (`operation = "Module"`, `target` = the module), a refused
  `Replace` — each with the version that made it. Only the reason is kept,
  never what was sent; messages are cut to 400 bytes.
- **Refusals** are `Exception`s with a `stage`: `request`, `source`,
  `binding` (with `missing`), `activation`, `absent`, `stopped`, `busy`,
  `stale`.
- **From inside**: a hosted program's base may ask about, stop or unload
  that very program while it is answering; an `Unload` then takes effect
  once its `Send` has answered, and a second `Send` into it is `busy`.

`Load`, `Send`, `Unload` and `Loaded` answer as before; `Loaded` answers
gain `version` and `hash`, and `Programs` items gain `version`, `hash`,
`state` and `failures`.

`code handlers` now also lists `emits`: every name the source emits to,
read from the parsed program. A shared gene's description (euglena 0.9.0)
derives the organelles it needs from it.

Tested in both output modes and the compiled one (`tests/interpreter_manage.code`).
